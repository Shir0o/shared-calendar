# Overlaps are normal

The calendar previously treated overlapping timed events as conflicts and surfaced them through badges, event warning icons, a top-bar count, and create/import warnings. Feedback on issue #960 showed that this warning language made simultaneous events feel disallowed. We removed those indicators and made **Overlap** a normal scheduling state: simultaneous events are allowed and render alongside each other, using Google Calendar’s interaction model as the reference. Busy-time detection remains only in scheduling helpers such as “Find free slot.”
